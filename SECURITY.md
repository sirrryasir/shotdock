# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within `shotdock`, please DO NOT open a public issue.

Instead, please submit a report through GitHub Private Vulnerability Reporting on the repository. You can also contact the maintainer directly.

All security vulnerability reports will be acknowledged within 48 hours, and a coordinated disclosure timeline will be followed.
